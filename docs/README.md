# Handoff: Kubix — магазинный лендинг + прототип генератора (вариант I «Shop»)

## Overview
Новый визуальный слой для репозитория `torgo1881-create/KUBIX` (Next.js 14 + Tailwind + shadcn-подобные `ui/`). Это лендинг фото-конструктора с каталогом наборов, примеркой «до/после», блоками «в подарок», FAQ и вводом кода из коробки. После него идёт 5-шаговый генератор: **Набор → Фото → Кадр → Вариант → Сборка**.

## About the Design Files
Файлы здесь — **дизайн-референсы в HTML**, не продакшн-код. Задача — **воссоздать этот дизайн в существующем коде KUBIX** (React-компоненты в `src/components`, Tailwind), сохранив существующие алгоритмы (`src/algorithms`, `src/services`, `src/workers`). `kubix-engine.js` — упрощённая демо-логика (палитры, пресеты, простая обработка и мозаика) только для прототипа. **Его НЕ переносить** — в проекте есть настоящие `mosaicGenerator`, `variants`, `blockGenerator`, `pdfGenerator`.

- `KUBIX I Shop.dc.html` — исходник дизайна. Разметка с инлайн-стилями: все цвета, размеры и тексты можно читать прямо отсюда. Синтаксис `{{ x }}` — это данные, `<sc-for>` — цикл, `<sc-if>` — условие.
- `kubix-engine.js` — откуда берутся данные для шаблона (функция `vals()`), там видно состояние и переходы.
- `preview-standalone.html` — собранная версия, открывается в браузере, чтобы посмотреть вживую.

## Fidelity
**High-fidelity.** Цвета, шрифты, радиусы, отступы и тексты финальные. Воспроизвести точно, через Tailwind-токены.

### Типографика
- Заголовки и названия наборов: **Montserrat Alternates** 800, letter-spacing -0.02…-0.03em.
  - H1 hero: `clamp(40px, 5.8vw, 78px)`, line-height 1
  - H2 секций: `clamp(30px, 3.8vw, 48px)`, lh 1.05
  - Название набора в карточке: 20px. Цифры шагов: 48px, цвет accent.
- Текст: **Mulish** 500 / 700 / 800, база 16px, lh 1.55. Лид: 19px. Мелкий: 13–14px.
- Подключение: Google Fonts `Montserrat+Alternates:wght@600;700;800` и `Mulish:wght@400;500;600;700;800`. В `layout.tsx` заменить IBM Plex.

### Радиусы
10px (кнопки в карточках) · 12px (кнопки, поля) · 14px (большие CTA, подложки превью) · 18–22px (карточки) · 24px (панели генератора) · 28px (CTA-баннер) · 999px (бейджи).

### Тени
- Карточка видео в hero: `0 20px 40px -20px rgba(20,48,47,.5)`.
- Тонкая рамка вместо border: `box-shadow: inset 0 0 0 1px #E2D9CC`. Выбранная карточка: `inset 0 0 0 2px #C8471F`.

### Отступы

- превью: подложка ink, radius 14, aspect 3/4, внутри мозаика пользовательского фото в палитре и сетке этого набора (`aspect = w/h`);
- название (20px) и категория справа (Classic / Color);
- dl: Картина `51×51 см`, Деталей `≈ 6 300`, Цвета — ряд квадратиков 12px;
- две кнопки друг под другом, обе 42px высотой, radius 10, 15px 700:
  - «В корзину»: accent, hover `#A93A17`;
  - «Примерить»: белая, border 1.5px ink, hover — заливка ink и белый текст. Ведёт на шаг 2 генератора с этим набором.

Данные — `PRODUCT_PRESETS` + `describePreset()` из `src/config/productPresets.ts`. Превью строить существующим генератором (низкое разрешение, кэшировать).

### 3. «Как это работает» (`#how`)
3 карточки, `auto-fit minmax(260px,1fr)`. Белые, radius 22, padding 26. Третья тёмная (ink, цифра peach). Цифра 48px accent, заголовок 20px 800, текст muted.
1. «Выбери набор» — Classic в оттенках серого или Color с тёплыми тонами. От 51×51 до 76×76 см.
2. «Загрузи фото в генератор» — Код для сборки лежит в коробке. А примерить можно бесплатно, ещё до покупки.
3. «Получи инструкцию» — Схема по блокам с номерами цветов, на экране или в PDF. Надоело фото — пересобери с новым.

### Генератор (5 шагов)
- **Шаги**: белая плашка radius 16, padding 6. Кнопки шагов: radius 11, 14px 800. Активный — accent и белый текст, пройденный — mint, будущий — прозрачный с muted-текстом. Клик ведёт на шаг.
- Заголовок шага (Montserrat Alternates 800, `clamp(30px,4.2vw,52px)`) + подзаголовок muted 17px. Тексты — массивы `TITLES` и `SUBS` в `kubix-engine.js`.
- **Шаг 1 — Набор.** Карточки как в каталоге, но целиком кликабельны. Выбранная — inset-рамка 2px accent.
- **Шаг 2 — Фото.** Dropzone (2px dashed, radius 24, min-height 340) + панель «Сейчас загружено» с превью и кнопкой «Продолжить с этим фото». Использовать существующий `UploadDropzone` (вставка из буфера, валидация).
- **Шаг 3 — Кадр.** Слева исходник с рамкой 3px accent: затемнение снаружи `box-shadow: 0 0 0 9999px rgba(20,48,47,.6)`, перетаскивание pointer-событиями, масштаб 1–3. Справа живое превью мозаики в подложке ink. Использовать `ImageCropper`.
- **Шаг 4 — Вариант.** 4 карточки: превью на ink, название, оценка в бейдже, mint-бейдж «лучшая оценка», описание, кнопка «Выбрать» / «Выбран» (выбранная — ink). Данные — `VariantCards` / `VARIANT_PRESETS`.
- **Шаг 5 — Сборка.**
  - Сводка: набор · размер · вариант · детали, справа размер блока 4×4 / 8×8 / 16×16 и «Скачать PDF».
  - Основная колонка: «Шаг N из M», id блока, прогресс 8px accent, сетка блока на ink (gap 3, клетки radius 3, номер цвета контрастным цветом), чипсы «деталей в блоке».
  - Боковая колонка: мини-карта всей мозаики с рамкой текущего блока (3px accent + затемнение) и легенда цветов с итогами.
  - Логика и PDF уже есть: `BuildMode` + `pdfGenerator`.
- **Нижняя панель (sticky).** «← Назад» и accent-кнопка «Дальше: …» («Дальше: фото», «Дальше: кадр», «Показать варианты», «Собирать этот вариант»).

## Interactions & Behavior
- «В корзину» → счётчик +1, тост «<Набор> добавлен в корзину». Тосты живут 2.8 с: тёмный фон, radius 14, внизу по центру. **В продакшне — реальная корзина и оформление заказа.**
- «Примерить» в карточке → генератор, шаг 2, с этим пресетом.
- Загрузка фото на лендинге пересчитывает hero, превью каталога и примерку. Всё в браузере, без сервера.
- Hover: кнопки меняют фон, переходы мгновенные. В продакшне можно `transition: background-color 150ms`.
- Адаптивность: все сетки на `auto-fit/minmax`, колонки переносятся без медиазапросов. Ряд шагов скроллится по горизонтали.

## State Management
`screen` (landing | app), `step` 1–5, `presetId`, `crop {z,x,y}`, `variantId`, `blockSize` (4/8/16), `block` (индекс), `photo` (canvas/файл), `cart`, `faqOpen`, `compare` (0–100), `boxCode`, `toast`. Кэшировать результаты мозаики по ключу (фото, пресет, кадр, вариант). Тяжёлые расчёты — в `mosaicWorker`.
