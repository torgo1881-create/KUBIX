# Шрифт для PDF

`DejaVuSansMono.ttf` — DejaVu Fonts (Bitstream Vera / Public Domain-подобная
лицензия, свободна для любого использования и распространения).

Шрифт встраивается в PDF целиком как CIDFontType2 с кодировкой Identity-H:
без этого кириллица в PDF не отображается, потому что базовые шрифты PDF
знают только WinAnsi. Моноширинный выбран сознательно — в таблицах инструкции
цифры выстраиваются в колонку.

Заменить можно любым TrueType с кириллицей: положите файл сюда и передайте
его путь в `loadPdfFont('/fonts/ВашШрифт.ttf')`.
